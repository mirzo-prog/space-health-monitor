Что делает система

Комплексное решение для мониторинга здоровья экипажа с защитой от кибератак и встроенным ИИ-ассистентом.

❤️

Биометрия в реальном времени

Мониторинг пульса, насыщения кислородом (SpO₂) и уровня радиации для каждого члена экипажа. Графики обновляются непрерывно.

🛡️

IDS — Защита сети

Обнаружение MITM-атак через HMAC-SHA256 и DoS-атак через rate limiting. Все инциденты логируются в файл.

🤖

ИИ-ассистент (Ollama)

Каждые 15 секунд модель llama3 анализирует последние 10 записей телеметрии и выдаёт медицинское заключение.

🔴

Red Team симуляция

Генератор создаёт реалистичные биоданные и с 5% вероятностью инжектирует MITM- или DoS-атаку для тестирования IDS.

🎨

Sci-Fi GUI

Полупрозрачное frameless окно в тёмных тонах, неоновые акценты, живые графики (pyqtgraph), мгновенные алерты.

⚡

Многопоточность

Сервер IDS и ИИ-анализатор работают в QThread — интерфейс никогда не зависает, даже под нагрузкой.

Система обнаружения вторжений

IDS детектирует два класса атак в реальном времени без остановки системы.

⚔️ MITM — Подмена пакетов

Каждый пакет подписан HMAC-SHA256. Если подпись не совпадает — пакет отклоняется, инцидент логируется. Атакующий не может подделать подпись без знания секретного ключа.

HMAC_SECRET = b"space_station_alpha_secret_key_2024"

💥 DoS — Флуд пакетами

Скользящее окно в 1 секунду считает пакеты от каждого источника. Превышение порога блокирует источник и фиксирует инцидент. Защита работает в отдельном потоке.

DOS_RATE_THRESHOLD = 10 пакетов/сек

Как запустить

Два терминала — и система работает. Ollama опционально.

bash — /home/mirzo/space-health-monitor
# 1. Установить зависимости
$ pip install -r requirements.txt

# 2. Терминал 1 — GUI + сервер IDS
$ python gui_dashboard.py

# 3. Терминал 2 — Генератор (Red Team)
$ python generator_red_team.py

# Ollama (опционально для ИИ-анализа)
$ ollama pull llama3 && ollama serve
